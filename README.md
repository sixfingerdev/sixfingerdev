### What I'm exploring

- **Efficient language models** — memory use, sparsity, low-rank methods, and the trade-off between speed and quality.
- **Coding agents** — tool-use workflows, evaluation, and improving training data from real development sessions.
- **Practical infrastructure** — inference, APIs, and running useful models on limited hardware.

### How I work

I like small, measurable experiments. A failed hypothesis is still useful when the setup, results, and limitations are documented clearly.

The pinned repositories below are a snapshot of current experiments and projects, not a claim that every idea is a finished product.
